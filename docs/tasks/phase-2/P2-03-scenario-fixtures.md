# P2-03 — Scenario fixtures and the differential test runner

- **Status:** done
- **Depends on:** P2-02
- **Size:** M (fixtures + one test class)

## Goal

Write ~40 small hand-made inputs covering the emulator's features, generate their expected snapshots with the oracle,
and run them all against `TerminalCore` in one `[Theory]`.

## Files to create or change

- `tests/LoomTerminal.Core.Tests/Conformance/Fixtures/scenarios/*.input` — create (list below)
- `tests/LoomTerminal.Core.Tests/Conformance/Fixtures/scenarios/*.json` — generated by the oracle
- `tests/LoomTerminal.Core.Tests/Conformance/ScenarioConformanceTests.cs` — create
- `tests/LoomTerminal.Core.Tests/LoomTerminal.Core.Tests.csproj` — copy `Conformance/Fixtures/**` to the output

## Design decisions (already made — do not change)

- One `[Theory]` with `[MemberData]` listing every `.input` file name; the test name shows the fixture name.
- Scenarios (one file each, named like this): `text-and-crlf`, `autowrap`, `autowrap-off-decawm`, `wide-chars-wrap`,
  `combining-marks`, `emoji-v11`, `tabs-default-and-hts`, `cursor-cup-clamp`, `origin-mode`, `scroll-region-lf`,
  `scroll-region-il-dl`, `scroll-up-down-su-sd`, `ich-dch-ech`, `el-ed-all-modes`, `decsca-selective-erase`,
  `sgr-16-colors`, `sgr-256-colors`, `sgr-truecolor`, `sgr-colon-forms`, `sgr-underline-styles`, `sgr-reset`,
  `inverse-and-invisible`, `alt-screen-1049`, `alt-screen-47-1047`, `save-restore-cursor`, `dec-special-graphics`,
  `insert-mode-irm`, `linefeed-mode-lnm`, `rep`, `decaln`, `ris-full-reset`, `decstr-soft-reset`, `osc-title`,
  `osc8-hyperlink`, `resize-narrower`, `resize-wider`, `resize-rows-scrollback`, `scrollback-trim`,
  `bracketed-paste-mode`, `mouse-modes`.
- Each `.input` starts with a `# <one-line description>` comment line (ignored by both readers: add `#` comment
  support to both, P2-01's reader and the oracle, as part of this card).
- **When a scenario differs from the oracle, the C# port is wrong** (fix it in this card if small; otherwise open a
  follow-up card in `docs/tasks/README.md` and mark the fixture `[Skip]` with the card id).

## Result

All 40 scenarios match xterm.js with no change to the C# port (plus the two P2-02 sample fixtures, kept as extra scenarios).
The ST terminator of `osc-title` is written `\x5c` since the `.input` format has no backslash escape.
